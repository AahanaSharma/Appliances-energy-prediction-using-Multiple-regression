# Appliances Energy Prediction

## Project Overview

This project uses Multiple Linear Regression to predict household
appliance energy consumption based on environmental conditions.

## Dataset

The dataset contains household energy consumption, temperature,
humidity and weather measurements recorded at 10-minute intervals.

## Machine Learning Model

- Algorithm: Multiple Linear Regression
- Target variable: Appliances
- Features:
  - T1
  - T2
  - T3
  - RH_1
  - RH_2
  - T6
  - RH_6
  - Visibility

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Results

The model was evaluated using a train-test split of 80:20.

## Visualization

The project includes an Actual vs Predicted Appliances scatter plot.
